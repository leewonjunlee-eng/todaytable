# 성비 규칙과 회차 참가자 보기

## 문제와 결과

회차 카드는 긴 일정 목록 아래의 참가자 표만 필터링해 변경된 결과를 놓치기 쉬웠습니다. 이전 검색어도 남아 다른 회차의 참가자가 없는 것처럼 보일 수 있었습니다. 이제 선택하면 참가자 제목에 포커스를 주고 목록으로 이동하며, 검색어를 초기화합니다. 날짜·지역이 같은 내부 회차를 하나로 묶고 한 신청의 여러 회차 선택은 중복 집계하지 않습니다. 목록에는 성별과 남녀 인원 요약을 추가했습니다.

성별 균형은 기존에 점수 요소였습니다. 이제 `isAllowedGenderComposition`이 4명 2:2, 5명 2:3·3:2, 6명 2:4·3:3·4:2만 허용합니다. 자동 탐색의 완성 후보, 제안 생성, 승인 재검사, 식탁 프로비저닝, 수동 재구성, 재배치와 빈자리 수락에서 같은 검사를 사용합니다. 부분 조합은 완성될 여지가 있는 경우만 탐색하고, 성별 미선택은 임의 배정하지 않습니다. 큰 모집군은 다음 식탁에 필요한 남녀 인원도 고려해 불필요한 잔여 인원을 줄입니다.

취소 후 네 명 이상이어도 3:1처럼 성비가 깨지면 EXCEPTION 상태와 재배치 작업으로 전환합니다. 확정된 예정 식탁의 성비가 달라지는 프로필 변경은 409와 입력 항목 안내를 반환합니다. PostgreSQL에서는 매칭과 같은 트랜잭션 잠금으로 변경과 승인 사이의 경합을 제어합니다.

## 가상 배치 v2

`source-lifecycle-v2-gender`는 원본 294행 각각을 별도 참가자로 유지하면서 허용된 성비, 같은 지역, 연령 차이 8년 이내, 공통 관심사와 MBTI를 고려합니다. 원본 성별은 그대로입니다. 지난 만남 71명·예정 80명·신청 중 143명, 체험 계정을 포함한 확정 식탁 31개입니다. 여섯 성비 조합이 모두 존재합니다. 체험 계정의 연결 식탁을 포함한 구성입니다.

| 인원 | 남 / 여 | 식탁 수 |
| --- | --- | ---: |
| 4명 | 2 / 2 | 7 |
| 5명 | 2 / 3 | 6 |
| 5명 | 3 / 2 | 3 |
| 6명 | 2 / 4 | 9 |
| 6명 | 3 / 3 | 4 |
| 6명 | 4 / 2 | 2 |
| 합계 | | 31 |

체험 계정은 제공된 설문 프로필의 성별에 연결하며 `SHOWCASE_REVIEW_PROFILE_LINKED` 감사 기록에 이전 값과 원본 행을 남깁니다. 그 외 원래 계정 정보와 비밀번호를 바꾸지 않습니다. 이전 가상 배치의 예정 신청·식탁·예약과 작업은 정리하고 원본·결제·이력은 보존합니다. 이는 실사용자 기록의 일괄 삭제나 실제 환불 처리가 아닙니다.

## 검증

`tests/gender-composition.test.ts`는 모든 남녀 인원 경우와 미선택, 성비 점수 0인 정책의 우회를 검사합니다. 기존 성공 시나리오의 미선택 성별 테스트 자료는 명시적인 남녀 조합으로 바꾸었으며 기존 결제·권한·일정·재배치 결과 단언은 유지했습니다. 자동 매칭 테스트에는 승인 전 성별 변경, 3:1이 되는 취소, 확정 후 프로필 변경 차단을 추가했습니다. 원본 기반 테스트에는 성비, 재실행, 이전 배치 보존·정리를 포함했습니다.

`tests/gender-browser.py`는 실제 원본의 294행 성별 연결과 모든 식탁의 성비를 확인하고, 회차 선택 후 목록·검색어·포커스·모바일 넘침을 검사합니다. 여러 내부 회차를 선택한 한 신청을 한 번만 세는 화면 회귀 검사도 포함합니다. 운영 실행에는 보호된 계정 JSON을 `--credentials`로 전달하며 결제나 참가 취소 요청은 보내지 않습니다.

최신 실행 결과와 배포 근거는 [STATUS](STATUS.md)에 모읍니다. 이 작업에는 설치한 frontend-design·webapp-testing 지침을 적용했습니다.
