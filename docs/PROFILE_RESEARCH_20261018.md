확인일: 2026-10-18. 공개 공식 웹사이트와 도움말을 대상으로 조사했다. 앱에 로그인해 비공개 화면을 직접 체험한 조사는 아니며, 실제 한국판 위피의 문항·알고리즘을 복제했다고 주장하지 않는다.

다른 서비스의 얼굴 사진 심사·외모 평가·유료 메시지 절차는 소규모 식사 모임의 PRD에 필요하지 않아 가져오지 않았다. 로고·화면·문구·진단 질문은 복제하지 않았다.

## 실제 구현

`/profile/test`에서 모바일 8단계로 진행한다.

1. 이름·연락처·출생연도·성별·직업·본인이 알고 있는 MBTI.
2. 관심사를 복수 선택한다.
3. 처음 만난 식탁에서의 시작 방식: 잔잔함 / 활기참.
4. 대화가 잘 통하는 순간: 깊은 대화 / 가벼운 유머.
5. 대화에서 편한 역할: 경청 / 화제 이끌기.
6. 만나고 싶은 사람의 성향을 복수 선택한다.
7. 희망 식사 예산과 못 먹는 음식·알레르기.
8. 결과 설명, 실제 반영할 성향을 직접 수정, 개인정보·운영 정책 동의 후 저장.

문항과 결과 문구는 오늘의 식탁을 위해 새로 작성했다. 심리검사나 MBTI 진단으로 표현하지 않는다. MBTI는 상황 답변으로 추정하지 않고 본인이 선택한 기존 유형을 사용한다. 결과는 대화 취향을 설명하는 안내다.

선택 답변은 `profile_tests`에 사용자별로만 보관하며, 서버에서 문항 ID·보기 ID·누락·추가 키를 검증한다. 저장 시 `profiles`와 테스트 응답 및 감사 기록을 하나의 트랜잭션으로 처리한다. 사용자가 결과 확인에서 고친 성향을 `profiles.traits`에 저장하므로 그 값이 실제 매칭 입력이다. 다른 참가자에게 원답변이나 연락처를 공개하지 않는다. 이전 프로필과 저장된 응답을 다시 불러오며, 기존 프로필 수정은 응답 기록을 지우지 않는다.

신규 가입은 `/signup` → 자동 로그인 → `/profile/test`로 연결한다. 가입 역할은 서버가 참가자로 고정한다. 비밀번호는 scrypt 해시, 세션은 HttpOnly 쿠키로 처리한다. 이메일 발송·소셜 인증·실제 과금은 연결하지 않는다. 프로필이 없는 기존 참가자도 로그인 후 테스트로 안내한다.

## 검증

`tests/profile-onboarding.test.ts`는 답변 매핑, 유효하지 않은 응답 미저장, 가입 역할 강제, 중복 가입, 비밀번호 해시, 프로필·응답 저장, 사용자별 조회 범위, 수정 시 재사용, 정지 계정 로그인 차단을 검증한다. SQLite와 PostgreSQL의 격리된 데이터베이스에서 각각 2개 테스트가 통과했다. `tests/profile-onboarding-browser.mjs`는 격리된 로컬 서버에서 360·390·430px 화면의 신규 가입, 8단계 진행, 이전 답변 유지, 결과 수정, 실제 저장, 재진입을 확인한다. 24개 확인이 통과했고 가로 넘침과 JavaScript 오류가 없었다. 외부 웹폰트 요청은 브라우저 검증에서 차단해 기본 글꼴에서도 동작하는지 확인했다.
