# 현재 현황 — 2026-10-19 성비 규칙·회차 참가자 보기 수정

신청 중의 **이 회차 참가자 보기**를 누르면 선택한 날짜·지역의 참가자 목록으로 이동하고 제목에 포커스가 갑니다. 같은 날짜·지역의 내부 회차는 한 카드로 묶으며, 여러 회차를 선택한 신청도 한 번만 집계합니다. 회차를 바꾸면 참가자 검색이 초기화되고, 남녀 인원과 개별 성별을 확인할 수 있습니다.

## 성비 필수 조건

아래는 **남 / 여** 순서입니다. 매칭 점수·정책과 별개로 자동 매칭, 수동 승인·재구성, 재배치, 빈자리 충원에서 모두 적용합니다.

| 식탁 인원 | 허용 조합 |
| --- | --- |
| 4명 | 2 / 2 |
| 5명 | 2 / 3, 3 / 2 |
| 6명 | 2 / 4, 3 / 3, 4 / 2 |

성별 미선택을 임의로 남녀에 포함하지 않습니다. 취소로 성비가 깨지면 네 명 이상 남아도 재배치가 필요합니다. 확정된 예정 식탁의 성비가 깨지는 프로필 변경은 운영팀 확인 안내와 함께 차단합니다. 변경된 프로필·동의·정원을 승인 시 다시 검사합니다.

체험 계정의 연결 신청까지 포함하면 참가자 295명, 신청 307건, 확정 식탁 **31개**, 후기 56개, 참가자 대화 124개입니다. 허용된 여섯 성비 조합이 모두 포함됩니다. 성비·연령·지역 조건을 충족하지 못한 응답은 신청 중으로 남겨 두며 원본 성별을 바꿔 맞추지 않았습니다.

기존 체험 계정의 미선택 성별은 제공된 설문 프로필에 연결하고 원래 값과 연결 행을 감사 기록에 남겼습니다. 로그인 계정·비밀번호·이름·기존 기록은 유지합니다. 이 계정은 실제 신원 추론의 대상이 아닌 가상 운영 체험 계정입니다.

이전 가상 배치는 기록으로 보관합니다. 해당 배치의 미래 신청·식탁·예약을 취소 상태로 바꾸고 예정 작업을 종료해 새 배치와 중복 진행되지 않게 했습니다. 기존 4개 식당의 자료는 유지하며, 새 배치가 사용하는 가상 식당 5곳에는 영업 슬롯 적용을 활성화했습니다. 원본 파일과 294개 응답, 계정·결제·과거 기록을 삭제하지 않았습니다. 결제·예약은 MOCK, 외부 푸시는 차단 상태입니다.
