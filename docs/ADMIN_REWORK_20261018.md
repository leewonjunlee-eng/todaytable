# 운영 어드민 개편과 PRD 정합성

이 문서는 운영 개편 당시 기록입니다. 이후 021~028 보완과 최신 검증·운영 배포는 [현재 현황](STATUS.md) 및 [2026-10-19 릴리스](RELEASE_20261019.md)를 확인하세요.

기준: 사용자의 최신 운영 화면 개편 요청, `files/우연한식탁_PRD.pdf` v0.2 전체, CTO 온보딩 자료, `kickoff_summary.md` 심사 배점.

최신 요청이 이전의 수동 승인 요구를 대체한다. PRD MAT-01/10에 따라 마감 전에는 접수 현황을 보여주고, 마감 후 정상 조합은 자동 확정한다. 별도 참석/예외/작업알림/안전검토 메뉴를 제거한다. 기존 기록과 참가자 안전 제약은 보존한다. 실제 결제·환불·이메일·외부 식당 예약 요청은 연결하지 않는다.

## 이어서 수행한 통합 검증 — 2026-10-19

현재 변경은 로컬 작업 트리에 있으며 이번 작업에서는 푸시·배포하지 않았다. `docs/PRD_TRACEABILITY_20261018.md`의 요구사항별 경로와 함께 확인한다.

- 전체 테스트: SQLite 기본 실행 64개 통과·PostgreSQL 전용 5개 건너뜀. PostgreSQL URL을 설정한 전체 실행은 69개 통과·실패 0·건너뜀 0 (`.data/resume-tests.log`, `.data/resume-postgres-tests.log`).
- 신규 PRD 흐름의 PostgreSQL 검증: 자동 매칭·대기자·개인정보 내보내기, 운영 화면·예약·재구성, 가입·프로필, 가상 결제·환불을 격리된 스키마에서 16개 통과 (`.data/resume-prd-postgres.log`).
- SQLite·PostgreSQL 각각 20개 인수 시나리오와 마이그레이션 2회 실행 통과 (`tests/scratchacceptance-newresults.json`, `.data/resume-providers.log`).
- 타입 검사와 프로덕션 빌드 통과 (`.data/resume-typecheck.log`, `.data/resume-build.log`).
- 360·390·430px 가입·프로필 24개, 결제 실패·취소·재시도·영수증·부분 환불 12개 확인 통과. 전액 환불 선택→실제 로컬 워커→완료 영수증도 통과 (`.data/profile-browser/results.json`, `.data/payments-browser/results.json`, `.data/payments-browser/full-refund-results.json`).

최초 기본 테스트 실패는 추가된 `prd-v2`를 누락한 정책 비교 기대값이었다. 정책 ID 5개 전체를 확인하도록 수정했다. 프로필 PostgreSQL 검증도 공용 스키마를 사용하지 않도록 전용 임시 스키마 생성·정리를 추가했다. 샌드박스의 하위 프로세스·브라우저 실행 차단은 승인된 권한으로 다시 실행해 제품 오류와 구분했다.
