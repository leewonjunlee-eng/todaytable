# 링크로 시작하는 참가자·운영자 체험 가이드

2026-10-20 UTC. 기준 커밋 `c56b3f2` 이후 개선.

## 완성한 경험

홈의 첫 방문 안내에서 참가자와 운영자 중 먼저 볼 역할을 선택한다. 안내는 홈에서만 자동으로 열리고, 닫기·Escape·건너뛰기·역할 선택 모두 방문 기록을 브라우저에 보관한다. 기본 dialog의 키보드 동작을 사용하며, 입력 화면과 깊은 링크에서는 안내로 작업을 가로막지 않는다.

공개 `/guide`에서 로그인 없이 두 역할의 각 4단계를 살펴본다. 역할과 단계는 URL(`?role=operator&step=3`)로 공유할 수 있다. 실제 앱의 데스크톱·모바일 화면을 각각 촬영해 총 16개 이미지를 제공하고, 각 단계에 행동·결과 설명과 해당 기능으로 이동하는 링크를 둔다. 단계가 바뀌면 화면 밖에 있는 새 설명으로 이동한다. 메뉴·모바일 헤더·마이·로그인 화면에서 다시 열 수 있다.

- 참가자: 취향 입력 → 일정·참가권 → 확정된 식탁 → 후기·다음 만남.
- 운영자: 신청 → 자동 매칭 결과 → 식당·예약 → 문의·예외 처리.
- 가이드 진입 자체에는 계정이 필요 없다. 실제 개인 기록과 운영 기능은 기존 로그인·서버 권한 검사를 유지한다. 계정·비밀번호·세션·운영 DB는 가이드에 공개하지 않는다.

## 실제 앱을 둘러보며 함께 수정한 부분

- 모바일 운영자 메뉴에 이용 가이드·참가자 화면·로그아웃 추가.
- 운영 설정과 자동 처리 확인에서 운영자 메뉴 유지.
- 로그인 후 원래 선택한 화면·날짜·지역으로 복귀. 서버가 허용된 내부 경로만 검증하며 외부 주소·인증/API 경로·다른 역할의 경로는 거부.
- 세션 만료(401, 운영자 403)와 찾을 수 없는 자료(404)에 로그인·관련 목록 이동 제공. 새로고침 오류 시 기존 입력·화면 유지.
- 확정 전 대기 신청자가 있는 빈 화면은 새 신청 대신 신청 현황으로 연결.
- 체크인 가능 시간·참석 완료·행사 종료 이유 표시. 기존 시간·후기 적격성 정책은 유지.
- 신고·차단과 운영자 신고 검토 해시 링크가 접힌 영역을 실제로 펼치도록 수정.
- 비로그인 홈의 중복 조회·불필요한 폴링 제거, 신청 카드 일정의 한국 시간 기준 통일.
- 모바일 운영 현황의 매출 그래프와 매칭 카드가 바깥 페이지를 밀어내지 않도록 내부 너비 제한.
- 한국어 오류·없는 페이지에서 홈·가이드로 복귀 가능.

## Claude와의 공동 검토

로컬 Claude Code의 `claude-opus-5-5`를 지정해 성공한 검토 3회를 수행했다. Claude는 읽기 전용으로 코드와 공개 예정 이미지의 설계·사용성·접근성·로그인 경로를 검토했다. 테스트·브라우저·빌드 실행자는 Codex이며, Claude가 실행했다고 표시하지 않는다. 한 번 중단된 요청은 성공 검토에 포함하지 않았다.

1. 설계와 기존 앱: 홈만 모달, 지속 가능한 닫기, 공개 가이드, 비밀정보 없는 캡처, 로그인 복귀, 오류 복구, 한국 시간 문제를 제안.
2. 구현·이미지: 운영 설정 메뉴, 작은 화면 가독성, 단계 이동 후 설명 위치, 캡처 속 테스트 흔적, 세션 안내 문구를 재검토.
3. 수정 후 확인: 검토 범위 내 HIGH·MEDIUM 잔여 없음. 남긴 LOW 중 예약명 식별자·미래 만남 참석 표시·예약 대기와 확인 코드의 모순은 격리 fixture 정리 후 재촬영. 로그인 복귀 링크는 검색 조건도 보존하도록 보완.

원본 JSON·모델 메타데이터·원문·실행 로그는 `.data/final-guide/`에 보관하며 Git에는 넣지 않는다. 독립 정적 검토 결과는 앱 전체 무결함 보증이 아니다.

## 화면 자료의 출처

`tests/prepare-operator-browser.ts`로 준비한 전용 SQLite fixture를 `tests/prepare-experience-guide.ts`가 정리한다. 모든 표시 이름은 `체험 참가자 N`으로 바꾸고 연락처·예약명·메모·확인 상태를 가상 자료로 정리한다. 프로필 캡처는 개인 정보 입력 대신 대화 성향 질문을 보여 준다. 제공 설문 원본과 운영 DB를 캡처에 사용하지 않는다. 이미지의 일정과 건수는 촬영 시점 예시임을 가이드에 표시한다.
