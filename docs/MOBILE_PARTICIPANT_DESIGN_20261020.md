# 참가자 모바일 디자인 개선 — 2026-10-20

기존 종이색·숲색과 식탁 사진을 유지하면서 휴대폰에서 날짜, 장소와 다음 행동을 쉽게 읽도록 구성했습니다. 새 스타일은 참가자 화면의 700px 이하에 적용합니다.

- 홈: 세로 모집 목록과 한국 시간 기준 월·일 표시, 재방문 시 간결한 다음 신청 안내.
- 내 모임: 긴 제목을 위한 공간, 균등한 상태 탭, 참가자 아이콘 아래 독립된 대화방 버튼.
- 신청: 넓은 날짜·지역 선택, 참가권 라벨·가격 간격과 큰 입력 필드.
- 채팅·마이페이지: 정돈된 상단 행동, 읽기 쉬운 말풍선과 안내문, 분명한 메뉴 계층.
- 공통: 한글 단어 줄바꿈, 모바일 안전 영역, 44px 이상 주요 터치 영역, 키보드 포커스 보완.

## Claude 협의

Claude Opus 5.5를 읽기 전용으로 호출해 세 차례 협의했습니다. 첫 검토에서 모바일 화면과 기존 코드를 바탕으로 디자인 방향을 합의했고, 두 번째는 수정 화면과 CSS를 대조해 아바타 범위·탭 개수·한글 줄바꿈·버튼 배치를 보완했습니다. 최종 코드 검토에서는 배포를 막을 문제가 없다는 의견을 받았습니다. 남은 낮은 우선순위 포커스 잘림도 수정했습니다. Claude의 평가는 정적 검토이며, 실행 검증은 Codex가 수행합니다. 원문과 합성 계정 화면은 Git에 포함하지 않는 `.data/mobile-design/`에 보관합니다.

## 실행 검증

- `npm test`: 98개 중 93 통과, 실패 0, PostgreSQL 전용 5개 건너뜀.
- `npm run build`: production 빌드 및 TypeScript 통과.
- Playwright: 360·390·430px에서 참가자 10개 화면과 공개 홈 총 33개 확인 통과, JavaScript 오류 0.
- 날짜·지역·참가권 선택, URL 탭 복원, 주요 터치 영역, 채팅 입력 및 480px 높이 화면을 세 폭에서 확인했습니다. 실제 결제·메시지 전송은 수행하지 않았습니다.
- 700/701px 경계·1120/1440px 및 운영자 4개 화면 총 8개 범위 검사 통과.

첫 브라우저 실행에서 테스트가 주입한 초기화 코드가 빈 브라우저 문서의 sessionStorage에 접근해 오류가 발생했습니다. HTTP(S) 문서에서만 초기화하도록 테스트를 수정하고 전체 화면 검사를 다시 통과했습니다. 제품 코드 오류와 구분합니다.

참가자 가이드 4개 화면을 데스크톱 DPR 2·모바일 360/390/430px DPR 3의 16개 조합으로 재촬영했습니다. 각 PNG와 무손실 WebP의 디코딩 픽셀이 일치했습니다. 데스크톱 4장은 기존 파일과 동일하여 Git 변경은 모바일 12장입니다. 모든 계정·채팅·장소는 로컬 합성 fixture를 사용합니다. 실제 Safari/Android 기기의 검증은 수행하지 않았으며, 브라우저 검사는 Chromium의 모바일·터치·DPR 에뮬레이션입니다.
