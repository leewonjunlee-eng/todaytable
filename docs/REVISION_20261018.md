## 구현 결정

- MBTI는 여러 성격을 동시에 저장하는 방식이 아니라 16개 유형 중 자신의 유형을 고르는 선택 UI로 해석한다.
- 전체 대화방은 확정된 식탁의 모든 멤버가 참여하는 그룹 채팅으로 구현한다.
- 새 추천과 재배치 모두 승인 전에는 참가자에게 확정 식탁/채팅/확정 알림을 공개하지 않는다. 기존 확정 식탁은 유지한다.
- 식당 후기를 새로 공개할 때는 공개 동의를 분리하고, 기존 비공개 후기를 참가자에게 임의 공개하지 않는다.
- 첨부 목록은 최종 운영자 승인을 요청하므로 이전의 운영자 승인 없는 자동 확정 정책을 대체한다.
