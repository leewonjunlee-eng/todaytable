# 제출 전 최종 점검·디자인 스킬·Claude 교차 검증

2026-10-21 UTC. 기준 커밋 `fcdcbb9` 이후 로컬 수정입니다. 운영 DB·배포·GitHub 푸시는 수행하지 않았습니다. 사용자 요청에 따라 검증을 중지한 뒤 같은 수정본에서 재개했습니다.

## 검토 방법과 판단

Codex는 코드 대조·구현·격리 DB 검사·실제 standalone 번들 브라우저 검증을 담당했습니다. Claude Code의 `claude-opus-5-5`에는 읽기 전용 검토를 3회 맡겼습니다. Claude는 소스를 직접 다시 읽었고 테스트나 브라우저를 실행하지 않았습니다. [Claude 원문](CLAUDE_SUBMISSION_REVIEW_20261021.md)에 발견·반론·재검토를 구분했습니다.

Claude 최종 정적 판정은 **최종 실행 검사 통과를 조건으로 제출 가능, 남은 차단 이슈 없음**입니다. 기존 forest/sage 디자인을 유지하고, 제출 직전에는 실제 이용 흐름의 결함과 오류 복구를 보완했습니다. 3차에서 제안한 이전 경로의 조회 결과 방어는 이후 Codex가 적용하고 마지막 번들에서 다시 검증했습니다. 전 화면 무결함이나 WCAG 전체 적합을 보증하는 판정은 아닙니다.

GitHub에서 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)과 [Vercel web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)를 `.claude/skills/`에 내려받아 Claude에 적용했습니다. Vercel이 참조하는 [인터페이스 기준](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)도 내려받았습니다. 스킬은 다음 Claude 실행부터 프로젝트에서 사용할 수 있습니다.

## 발견과 수정

| 문제 | 최종 보완·검증 방식 |
| --- | --- |
| 로그인에서 가입하면 선택한 날짜·지역 소실 | 로그인→가입→프로필→원래 화면에 `next` 유지. 서버의 기존 허용 목록으로 재검사. 실제 가입·저장으로 세 모바일 폭 확인 |
| 프로필 작성 중단 계정의 재로그인 시 목적지 소실 | 로그인 API에서도 검증된 목적지를 프로필 입력으로 전달. 외부 URL·운영자 주소 거부 회귀 검사 |
| 성별 미선택 상태로 모든 온보딩을 마친 뒤 신청 제한 발견 | 신원 선택을 강제하는 새 정책 없이 초기 입력·프로필 수정·최종 확인에 기존 신청 조건 안내. 최종 확인에서 해당 입력으로 바로 이동 |
| 전송 응답 전에 입력한 다음 채팅 초안 소실 | 전송한 문구와 현재 입력이 같을 때만 초기화. 지연 POST로 수정 전 유실 재현 후 수정 |
| 응답 유실 후 문구를 바꾸면 요청 키 충돌 | 같은 문구 재시도는 키 유지, 바뀐 문구는 새 키 사용. 성공 후 같은 문구도 새 전송 가능 |
| 200개 초과 대화에서 최신 메시지 누락 | SQLite·PostgreSQL 쿼리 모두 최신 200개를 가져와 시간순 표시. 실제 DB에 205개를 넣어 6~205번과 `after` 결과 확인 |
| 반복 통신 실패마다 오류 배너 재생성 | 성공했을 때 오류 초기화. 기존 화면·입력·오류 노드를 유지 |
| 전송 전 시작한 조회를 전송 후 새로고침으로 재사용 | 진행 중인 조회 종료 후 새 GET 요청. 다른 식탁으로 이동하면 이전 경로의 결과·오류를 적용하지 않도록 경로 확인 |
| 신청 단계 변경 시 키보드 포커스 소실 | 단계 제목에 포커스 이동. 저장된 결제 대기 복원에는 자동 이동 생략. 노치 영역 스크롤 여백 반영 |
| 출석 정정 실패에도 편집창 닫힘 | 성공했을 때만 닫고 사유 초기화. 실패 시 상태·사유 보존 |
| 식탁 상세 예외 해결의 확인 절차 누락 | 해결 기록 전 확인창 제공. 취소 시 API 호출 없음 |
| 안전 신고 접수 후 같은 입력 잔류 | 성공 시만 초기화하고 운영팀 확인·추가 문의 경로 안내 |
| 알림 시각·모의 결제 표기 혼동 | 알림 시간을 한국 시간으로 고정하고 체험용 결제 결과 선택임을 명시 |

Claude 1차의 “성별 검증 없음” 지적은 부정확했습니다. 원래 검증 항목에 성별이 포함됐고 미선택 프로필 저장도 의도된 정책입니다. Codex가 반론하고 Claude가 HIGH를 철회했습니다. 선택권은 유지하고 신청 조건을 먼저 알리는 방식으로 합의했습니다.

## 실행 근거

실행 로그·임시 세션·가상 DB·캡처는 Git 제외 `.data/submission-review/`에 있습니다. 개인정보나 운영 계정은 보고서에 포함하지 않았습니다.

| 검사 | 확인 결과 |
| --- | --- |
| 전체 자동 테스트 | 98개 중 93 통과·실패 0·PostgreSQL 전용 5 건너뜀 (`tests-final.log`) |
| 빌드 | Next.js 16.4.2 production build·TypeScript 통과 (`build-final.log`) |
| 205개 실제 메시지·복귀 주소 | 격리 SQLite 검사 통과. 전체 테스트에 포함 |
| 실제 모바일 가입·온보딩 | 360·390·430px, 30개 확인 통과 (`onboarding/results.json`) |
| 채팅 지연·실패·키·전송 전 조회 경합 | 5개 확인 통과, JavaScript 오류 0 (`chat-draft.json`) |
| 가이드·참가자·운영자 여정 | 경로 방어 추가 전 360·390·430·1440px 17개 그룹 통과; 마지막 번들은 390·1440px 15개 그룹 재확인, JavaScript 오류 0 (`browser-final/`, `browser-release/`) |
| 모바일 조작·범위 분리 | 360·390·430px 조작 3개 그룹, 태블릿·데스크톱·운영자 범위 분리 8개 그룹 통과, JavaScript 오류 0 (`mobile-controls-final.log`, `mobile-scope-final.log`) |
| 오류 복구·포커스·확인 취소 | 5개 확인 통과, JavaScript 오류 0 (`polish.json`) |

메시지 전송·통신 장애·출석 충돌·안전 신고·해결 취소 사례는 브라우저의 통제 응답으로 재현했습니다. 실제 돈 이동이나 실제 다중 운영자 충돌을 검증했다는 뜻은 아닙니다. 가입·로그인·프로필 저장은 격리 서버의 실제 API를 사용했습니다. PostgreSQL 전용 테스트와 실제 iPhone 키보드·노치 동작은 이번 실행 범위에 포함되지 않습니다.

## 이후 발전 우선순위

1. 오래된 채팅 더 불러오기와 증분 조회 커서. 현재는 최신 200개를 표시하며 과거 기록을 삭제하지 않습니다.
2. 앱이 숨겨지면 폴링 중단·복귀 시 갱신. 모바일 배터리·데이터 사용을 줄이는 후속 개선입니다.
3. 실제 iPhone·스크린리더로 과업 완료와 키보드·포커스·메시지 자동 스크롤을 측정합니다.

재실행 방법은 [테스트 안내](../tests/README.md)의 격리 fixture 준비 절차를 사용합니다. 신규 검사는 `tests/chat-draft-browser.py`, `tests/submission-polish-browser.py`입니다. 이 결과는 로컬 코드 기준이며 제출 링크에 반영하려면 별도 Git 반영·배포가 필요합니다.
