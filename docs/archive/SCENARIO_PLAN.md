# 전체 시나리오 구현·검증 계획

2026-10-17. 사용자의 승인에 따라 주 에이전트가 계획·검토·통합·검증을 맡고 Luna 하위 모델 3개가 구현한다. Claude 검증은 제외한다.

## 구현 범위

1. 일반 취소의 이용권·모의 환불 처리, 4명 미만 테이블의 동의 범위 내 재매칭, 해결 불가 시 운영 예외 처리.
2. 제공된 원본 294건의 관리자 검색·검토와 명시적인 가정을 사용하는 시연 데이터 전환. 원본과 시연 계정·모의 결제를 구분한다.
3. 독립 워커 배포, 작업 재시도·푸시 실패 처리, 배포 이미지에 마이그레이션 도구 포함.

## 완료 판정

- SQLite와 별도 로컬 PostgreSQL에서 실제 마이그레이션·반복 실행, 결제/이용권 중복 방지, 자동 매칭·프로비저닝·미매칭 해결을 검증한다.
- 취소의 시간 경계·소유권·중복 요청, 재매칭의 인원/나이/동의/차단/제한 조건과 피드백의 다음 매칭 반영을 검증한다.
- Chromium에서 실제 참가자·운영자 로그인과 주요 화면 조작을 검증한다. 테스트 시각 변경·가상 데이터 생성은 격리된 검증 DB에 한정한다.
- 타입 검사·테스트·프로덕션 빌드를 통과한 소스를 웹/워커에 배포하고 운영 PostgreSQL 마이그레이션, 원본 데이터 보존, 역할별 접근, 워커 실행 상태를 확인한다.
- 실제 결제/식당 제공자는 MVP의 모의 제공자를 사용한다. 푸시는 설정·구독·성공/실패 전송 로직을 검증하며 실제 단말 수신 여부는 별도 증거로 구분한다.

## 분담

| 구현 담당 | 범위 |
|---|---|

| runtime (Luna) | 워커·배포 이미지·인증 보완·브라우저 시나리오 |
| 주 에이전트 | 요구사항/코드 검토·독립 실행 검증·배포·결과 기록 |
