## 캡처 인덱스 수정

[captures/index.csv](../../captures/index.csv)의 `timestamp`와 `timestamp_seconds` 값이 59행 모두 서로 바뀌어 있었다. 열 이름을 유지하고 값을 바로잡았다.

- 수정 전 첫 행: `timestamp=1`, `timestamp_seconds=00:01`
- 수정 후 첫 행: `timestamp=00:01`, `timestamp_seconds=1`
- 13번은 플랫폼 시연 화면이 아닌 슬라이드이므로 `demo screen` → `slide`로 수정했다.
- 28번은 플랫폼 화면이므로 `slide` → `demo screen`으로 수정했다.
- 47번은 발표자 카메라 화면이므로 `slide` → `speaker`로 수정했다.

파일명·캡처 순번·시간 표기 간 일치와 59개 이미지의 존재를 확인했다. 각 이미지가 녹음의 동일 시점과 정확히 동기화되는지는 검증하지 않았다.
